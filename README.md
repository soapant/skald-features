# skald-features

Features for [Skald](https://github.com/soapant/skald) that I use daily in my
own workflow. Skald ships with no widgets or remaps, so this repo is both a
set of working examples and a reference for writing your own.

> ⚠️ **Unofficial and unstable.** These are personal features written against
> Skald's current, unstable API (`skapi.h`). They can break when the API
> changes. Each feature lists the Skald version it was last tested with.

## Installing a feature

(Manual for now. Copy the feature's folder into your `FeaturePath`, then
reload features. See the Skald README for details. You need a C compiler(temporary).)
